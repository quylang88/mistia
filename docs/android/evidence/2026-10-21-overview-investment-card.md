## Behavior and source comparison

The actual Overview includes the missing investment card before budget/dues/recent. It reads the existing single owner-scoped six-entity snapshot, reports remaining inventory capital and signed persisted all-time realized profit/loss independently, and opens the existing investment route through MainActivity. The current destination is the known APK0 read-only investment list; this slice does not implement or claim APK4 CRUD/FIFO/private images, family subject permissions or the complete investment hub.

Direct source references: Swift OverviewView608–685 (active channel/assets, latest persisted position, all owner live trades, canonical accounting wallet),1443–1552 (card),2659–2667 (30px original icon) and InvestmentSummaryLogic398–445 (positive-quantity/nonnegative basis and signed all-time profit). Archived/deleted assets do not remove realized history; no date/kind filter or recomputed gross/FIFO substitutes for persisted realized results. Capital and profit damage are independent. Exact BigInteger aggregation follows established Android read reporting, preserving signed cancellation beyond Long; persisted/mutation/wire money remains Long.

Accounting currency uses the deterministic system wallet even when archived; only genuine absence/deletion uses primary. Required nonzero source snapshots must match the valid accounting ISO currency, avoiding relabelling USD cents as JPY/VND. Zero effects need no unused currency. A checked inventory selector shares the existing position calculation; actual Hero and card use this same checked capital. Existing minimal native position fixtures gain their required accounting_currency_code and realized-zero field; money/owner/outbox assertions remain. The accounting-wallet live-change test now explicitly holds mismatched positions until their stored currency also matches, then verifies its original exact FX result.

UI uses original registered assets, 13sp uppercase localized section header, 22dp group, 30dp icons,14x12dp row padding, chevrons, signed profit with plus for nonnegative including0 and teal/red color. Loading/failure/wrongowner display unavailable money, failure retries the shared read source, overlay disables opening. Loadedempty shows0/+0 in primary. Narrow/large-font amounts adapt from side-by-side to stacked text; extremely long numbers receive a full-width amount line and can wrap rather than clip if still wider.
